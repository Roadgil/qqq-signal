# QQQ 적립 신호판 — 설치 · APK 만들기

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 (계산 엔진 + 화면 전부 들어 있음) |
| `sw.js` | 오프라인 캐시 + 푸시 알림 처리 |
| `manifest.webmanifest` | 홈 화면 설치·APK 변환용 앱 정보 |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | 앱 아이콘 |

## 0. 바로 써보기 (PC)
`index.html`을 크롬으로 열면 바로 동작해요. (알림·설치는 아래 1번처럼 https 주소에 올린 뒤에 됩니다.)

## 1. 폰에 설치 (GitHub Pages, 무료 · 5분)
1. github.com 로그인 → 오른쪽 위 **＋ → New repository**
   - 이름: `qqq-signal` / **Public** 선택 → Create repository
2. 만들어진 저장소 화면에서 **uploading an existing file** 클릭 → 위 파일 6개(README 제외 가능)를 한 번에 끌어다 놓기 → **Commit changes**
3. 저장소 **Settings → Pages**
   - Source: **Deploy from a branch** / Branch: **main**, 폴더 **/(root)** → Save
4. 1–2분 뒤 `https://<내아이디>.github.io/qqq-signal/` 접속되면 성공
5. 폰 크롬으로 그 주소 열기 → **⋮ → 앱 설치(또는 홈 화면에 추가)**
6. 앱 열고 맨 아래 **데이터 · 알림 → 푸시 알림 켜기**

> API 키는 파일에 들어가지 않고 내 폰 브라우저에만 저장되니 Public 저장소여도 괜찮아요.

## 2. 진짜 .apk 만들기 (PWABuilder, 빌드 환경 설치 불필요)
1. 1번까지 끝낸 뒤 https://www.pwabuilder.com 접속
2. 내 주소(`https://<아이디>.github.io/qqq-signal/`) 입력 → Start
3. **Package For Stores → Android → Generate Package** (Package ID 예: `io.github.<아이디>.qqqsignal`)
4. 받은 zip 안의 `.apk`를 폰으로 옮겨 설치 (설치 중 "출처를 알 수 없는 앱" 허용)
5. 선택: zip 안의 `assetlinks.json`을 저장소에 `.well-known/assetlinks.json` 경로로 올리면 앱 상단 주소창이 사라지고 완전한 앱처럼 보여요.
6. zip 안의 서명 키(signing key) 파일은 나중에 업데이트용으로 꼭 보관하세요.

앱 내용을 고치면 GitHub에 `index.html`만 다시 올리면 됩니다. APK는 다시 만들 필요 없어요(웹 주소를 띄우는 구조).

## 3. 시세 데이터
- **기본(키 없음):** Yahoo Finance를 공개 CORS 프록시 경유로 조회 (QQQ 5년 일봉, QLD, TQQQ, ^VIX, KRW=X). 프록시가 막히면 다른 프록시로 자동 재시도.
- **권장:** twelvedata.com 무료 가입 → API 키를 앱 **데이터 · 알림**에 붙여넣기. QQQ/QLD/TQQQ/환율은 Twelve Data(실시간), VIX는 Yahoo로 받아요. 무료 한도 분당 8회 · 하루 800회 (새로고침 1번에 약 3–5회).
- 둘 다 실패하면 마지막으로 받은 값으로 계산하고, VIX·환율은 수동값을 쓸 수 있어요.

## 4. 알림 동작 방식 (한계 포함)
- 앱이 열려 있거나 백그라운드에 살아 있는 동안 설정한 주기(기본 10분)마다 시세를 받아 신호를 확인해요.
- 같은 신호는 하루(세션) 1번만 알려요. 구간별 **완료** 체크를 하면 그 구간 알림은 더 이상 오지 않아요.
- 앱을 완전히 종료하면 확인하지 않아요. 서버 없이 폰 안에서만 도는 구조라서예요.

## 5. 계산 규칙 요약
- **국면:** QQQ > 200일선 → 상승장(월 예산 60% QLD, 40% SGOV 파킹) / 아래면 하락장(100% QLD)
- **하루 권장액:** (이번 달 남은 QLD 예산 ÷ 이번 달 남은 미국 거래일) × 배수. 참고용으로 '월 배정 ÷ 20'도 표시
  - 가속 2배: RSI(14) ≤ 40 또는 전일 −2% 이상 하락 또는 VIX ≥ 25
  - 강한 가속 2.5배: VIX ≥ 30
  - 과열(RSI ≥ 70): 매수 쉼, 그 금액은 SGOV 파킹 (가속 조건보다 우선)
- **탄알(대기 현금) 분할매수:** 50주선 10% QLD · 100주선 20% QLD · 150주선 30% QLD · 200주선 20% TQQQ · 200주선 −10% 20% TQQQ (터치 = 당일 저가가 이평선 이하)
- **추세 돌파:** 50주선에 닿지 않은 상태에서, 최근 10거래일 안에 이평선 아래 마감이 있었고 지금 100일선·200일선을 **둘 다** +1% 버퍼 이상 넘으면 → 남은 탄알 전액 TQQQ
- **리밸런싱:** QQQ ≥ 50주선 +15% → 레버리지 평가액의 10% 익절(TQQQ 먼저) / +20% → 목표 현금 비중(기본 30%)까지 매도 / 매년 12월 정기 점검
- 모든 숫자(비율·배수·RSI·VIX 기준·버퍼·목표 비중·정기 점검 월)는 앱의 **전략 설정**에서 바꿀 수 있어요.
- 미국 휴장일(2026–2028) 반영. 2029년부터는 `index.html` 안의 `HOLIDAYS` 목록에 추가하세요.

계산 도구이며 투자 권유가 아닙니다. 주문 전 증권사 앱의 실제 가격을 확인하세요.

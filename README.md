# 심플 신호판 — QLD 매일 적립 + TQQQ 100·200일선

초심플 2축 전략 대시보드예요. 계산·알림 규칙은 아래 두 줄이 전부입니다.

## 전략
1. **QLD 코어 — 무지성 적립 (예산의 50%)**
   - 월 예산 250만 원 기준 QLD 몫 125만 원 ÷ 20거래일 = **하루 ₩62,500** 을 조건 없이 매일 QLD로 적립.
   - 비중(기본 50%)과 월 예산은 앱 설정에서 바꿀 수 있어요.
2. **TQQQ 위성 — QQQ 100·200일선 추세추종 (예산의 50%)**
   - 월 예산의 나머지 125만 원이 이 축의 몫. 보유 상태면 TQQQ로, 대피 상태면 SGOV에서 대기.
   - **보유(매수):** QQQ가 **100일선 +1%와 200일선 +1%를 동시에** 넘으면 TQQQ 매수·보유
   - **대피(매도):** QQQ가 **200일선 −2%** 아래로 이탈하면 TQQQ 전량 매도 → SGOV(현금)
   - 그 사이 구간은 직전 추세 유지(휩소 방지 관망)
   - 이평선은 **끝난 일봉 종가의 단순이동평균**(장중엔 오늘 봉 제외, 미국 마감 16:05 ET 이후엔 오늘 봉 포함).

## 시세 데이터
- **실시간(키 불필요):** TradingView 스캐너에서 QQQ(15분 지연 스트리밍)·QLD·TQQQ 현재가.
- **일봉 100·200일선:** Twelve Data `time_series`(기본 키 내장, 6시간 캐시) → 실패 시 Yahoo(공개 CORS 프록시).
- **환율:** Twelve Data `exchange_rate`(30분 캐시) → 실패 시 저장값/직접 입력.
- 자동 새로고침 기본 2분(1·2·5·10·30분·끄기).

## 알림
- Cloudflare Worker(`qqq-signal-push`)가 미국 정규장(09:25–16:15 ET) 5분마다 QQQ를 확인하고, **추세가 전환된 날 1회**만 Web Push를 보냅니다.
- 앱의 **설정 · 알림 → 백그라운드 푸시 켜기**로 구독하고, **테스트 알림**으로 확인하세요.
